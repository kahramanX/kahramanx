## 👋 About

I'm a software engineer. I've been building software professionally since 2021, first at an agency in Istanbul, where I worked on stores, backend services, integrations and platform migrations for 15+ retail and corporate brands (about 3M monthly visits in total). Now I work independently: I take on client projects as a freelance engineer and build my own products on the side.

On one retail store, rendering and Core Web Vitals work took Largest Contentful Paint from 3.8 s to 0.5 s and mobile Lighthouse from 52 to 95.

I start with how your business runs, then pick the stack. When AI is the wrong tool for a job, I say so.

More about what I do, with case studies, is on **[kahraman.pro](https://kahraman.pro)**.

## 🚀 What I'm building now

- **[SetupBook](https://setupbook.io)** is a free trading journal that syncs trades from MetaTrader, cTrader, TradeLocker, IBKR and exchanges. It includes Setup AI, a coach that answers from your own trades and writes a weekly review. I designed and built it alone: web app, iOS and Android app (bare React Native), payments and nine languages.
- **Market Hours: Forex & Stocks** is a mobile app (Flutter) with a live world map, session timeline and market clock, plus a web companion.
- **Passport.AI** is a passport, ID and visa photo app (Flutter, Firebase).
- **[Trading bot](https://github.com/kahramanX/trading-bot)** is an open-source crypto trading engine in TypeScript and CCXT, built around Smart Money Concepts and multi-timeframe analysis.

## 🛠 What I do for clients

- Web apps, internal tools, backends and APIs
- AI agents and LLM features that work on your own data (RAG, chatbots, MCP servers)
- Integrations that keep stores, CRMs, marketplaces and analytics in sync
- Performance work, migrations and rescuing software that stopped working

I work alone, so you talk to the person writing the code. You get the code, the access and short handover notes.
